# HRAgent 前端（React + Vite）

## 数据库准备

已有公司、用户和部门表后，在 hragent 数据库手动执行 `scripts/sql/007_positions.sql`。
不要重新执行以前的建表脚本。页面没有假岗位数据，也不会自动建表。
至少需要一个启用的部门，可以使用已有的测试部门，或由管理员在前端新增。

## 开发启动

终端一，在项目根目录启动后端：

```bash
conda activate edu_agent
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

终端二：

```bash
cd frontend
npm install
npm run dev
```

打开 http://127.0.0.1:5173。Vite 将 /api 请求代理至 http://127.0.0.1:8000，无需放开后端跨域。
后端端口变化时修改 vite.config.js 中的代理地址，并重启 Vite。

## 页面功能

- 独立登录页：用户名/邮箱和密码登录，可切换密码可见性。
- 登录后展示岗位工作台、所属公司和当前角色；管理员额外显示“部门管理”入口，HR 不显示。
- 管理员可查看、搜索和按启用状态筛选本公司部门，通过弹窗新增部门；同名冲突显示错误。新增成功后岗位中的部门选项同步更新。
- HR 与管理员均可新增、编辑本公司岗位；部门来自真实接口。
- 支持岗位名称/部门搜索、部门与状态筛选、分页。
- 维护计划招聘人数、已招聘人数，自动计算剩余空缺；招满与暂停/关闭分开展示。
- 岗位备注不等于正式 JD，尚未提供 JD 上传或简历筛选。
- 同部门同名岗位返回 409；不能把岗位放到其他公司或已停用的部门。
- Token 只存在当前标签的 sessionStorage，支持刷新恢复；恢复时重新校验身份。退出会清除 Token，密码不存储。
- 401 返回登录页；服务失败显示错误和重试，不伪造数据。

## 构建与预览

```bash
npm run build
npm run preview
```

preview 使用 http://127.0.0.1:4173，并代理至 8000 后端。
也可在 build 完成后重启后端，访问 http://127.0.0.1:8000/ui/，由后端提供 dist 中的构建文件。
原来的免构建静态页面已替换，不能直接双击源代码 HTML 打开。

不增加自动测试文件，可通过页面或 http://127.0.0.1:8000/docs 手动验证接口。

# 本地前端

无需 npm、构建或另起前端服务器。页面由 FastAPI 在 `/ui/` 提供，接口请求使用同一地址，因此不需要额外跨域配置。

在项目根目录运行：

```bash
conda activate edu_agent
python -m backend.main
```

打开 http://127.0.0.1:8000/，会自动进入 `/ui/`。如果后端修改为其他端口，使用对应地址打开即可；不要直接双击 HTML 文件。

已运行且没有开启自动重载的后端需要重启，才能注册新页面路由。

## 验证步骤

1. 确认已在 hragent 数据库手动执行 `scripts/sql/001_users.sql` 至 `006_seed_test_departments.sql`；只执行尚未执行的脚本，建表脚本不能重复运行。
2. 点击“登录账号”，使用 `hr_test` 或 `admin_test`，本地测试密码为 `HrAgent-Test123!`。
3. HR 可以查看公司资料、部门列表和部门详情；修改按钮禁用。
4. 退出并换成管理员登录，可以修改公司资料、新增和编辑部门，以及停用或启用部门。停用操作会先确认。
5. “请求记录”显示请求路径、HTTP 状态、耗时和错误说明，不保存请求正文、密码或 Token。

登录凭证只保存在当前页面内存中，刷新或退出后需要重新登录。后端仍执行真正的权限校验，前端按钮禁用仅用于操作提示。

右上角的“后端已连接”只表示 `/health` 可访问，不代表数据库和 Milvus 可用；成功登录或读取公司/部门才说明对应数据库查询成功。Milvus 暂无可用性检测接口，此页面不检测其端口。

本页面不会自动建表或插入数据，也不会自动保存表单。资料由后端真实读取；没有模拟数据。
